# 污水工程設計法規與重點規範 LLM Wiki

本專案為個人研究與工程筆記用途之「污水工程設計法規與重點規範」LLM Wiki 系統，依據 `AGENTS.md` 規範建構，為**嚴格封閉式知識庫（Closed-Book / Strictly Grounded）**，100% 僅依據 `papers/` 內 5 篇官方技術報告與國家法規標準撰寫。

---

## 📚 收錄文獻清冊 (`papers/`)
1. **01.下水道用戶排水設備標準.pdf**（民國 101 年發布，全 45 條文）
2. **02.建築物污水處理設施設計技術規範.pdf**（民國 108 年營建署版，全五章及附表）
3. **03.下水道工程設施標準 _ 內政部國土管理署全球資訊網.pdf**（民國 114 年 11 月 4 日令修正，上位法規最高標準）
4. **04.下水道系統設計及解說_第三章.pdf**（民國 113 年 1 月版，水量水質推估、廠區防洪配置與節能）
5. **05.下水道系統設計及解說_第四章.pdf**（民國 113 年 1 月版，管渠水理學、水力特性曲線、餘裕率、跌落井消能、CNS 15536 人孔蓋）

## 📁 系統目錄結構
- `papers/`：原始法規與技術手冊 PDF 檔案庫。
- `wiki/`：32 篇 Markdown 結構化工程筆記（全數無孤島頁面，累計標註 413 處精確出處標籤，156 處內部雙向連結 `[[...]]`）：
  - `index.md`：全庫目錄與頁面狀態總表。
  - `log.md`：系統歷程日誌。
  - `src_*.md`：5 篇原始文獻技術摘要。
  - `rule_*.md`：17 篇跨文獻法規紅線與關鍵設計參數。
  - `proc_*.md`：8 篇工法對比與實務施工檢核表。
- `presentation.html`：現代清爽教學卡片風獨立離線 HTML 互動簡報。
- `AGENTS.md`：LLM Wiki 系統架構、作業節點與防呆紅線規範。

---

## 🎨 互動簡報特色 (`presentation.html`)
- **風格 B（現代清爽教學卡片風）**：純白底色 (`#FFFFFF`)、湖水綠主色 (`#0D9488`)、柔和灰框 (`#E2E8F0`)，強制法規紅線採警示紅 (`#DC2626`) 凸顯。
- **全離線零依賴**：100% 原生 HTML/CSS/JS，杜絕生硬 LaTeX，改採 Unicode 數學符號與原生標籤。
- **跨篇法規參數對照表**：支援 Tab 分頁切換（管渠水力、水質單元、人孔附屬、特殊系統）。
- **即時合規檢核工具**：左側輸入設計參數，右側即時計算流速、流量與判定合規狀態（通過 ✅ / 超標 ⚠️）並標註 PDF 條文出處。
- **嚴格資料溯源膠囊**：每張投影片右下角固定標註引用之 Wiki 頁面與原始 PDF 條文頁碼。
