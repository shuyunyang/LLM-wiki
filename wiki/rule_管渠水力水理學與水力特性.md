# 規則彙整：管渠水力水理學與水力特性

## 1. 核心水理公式規範

### 1.1 重力流：曼寧公式 (Manning's Formula)
下水道重力管渠之水力計算，統一以曼寧公式為準 [03.下水道工程設施標準.pdf | 第10條 p.8] [05.下水道系統設計及解說_第四章.pdf | 4.2節 p.12]：
$$V = \frac{1}{n} R^{2/3} S^{1/2}$$
$$Q = A \cdot V = \frac{A}{n} R^{2/3} S^{1/2}$$
- $V$：斷面平均流速 ($\text{m/s}$)
- $Q$：流量 ($\text{m}^3/\text{s}$)
- $A$：水流斷面積 ($\text{m}^2$)
- $R$：水力半徑 ($\text{m}$)，定義為 $R = A / P$（$P$ 為潤周或濕周）
- $S$：水力坡降 / 管底坡度 (無因次，$\text{m/m}$)
- $n$：曼寧糙光係數 (Manning's Roughness Coefficient)

#### 曼寧糙光係數 $n$ 取值準則
依管材種類與長期營運沉積情況之設計取值：
| 管材種類 | 手冊建議新管範圍 $n$ [05.下水道系統設計及解說_第四章.pdf | 表4.2-1 p.15] | 設計實務安全取值 $n$ [05.下水道系統設計及解說_第四章.pdf | 4.2節 p.16] |
| :--- | :--- | :--- |
| **鋼筋混凝土管 (RCP)** | $0.013 \sim 0.015$ | **$0.015$** |
| **高密度聚乙烯管 (HDPE) / PVC 管** | $0.010 \sim 0.013$ | **$0.013 \sim 0.015$**（考量接頭及污垢） |
| **玻璃纖維強化塑膠管 (FRP)** | $0.010 \sim 0.012$ | **$0.013 \sim 0.015$** |
| **綜合長期營運建議標準值** | — | **$0.015$**（涵蓋污泥黏著、生長物與接頭水頭損失） |

### 1.2 壓力流：海森-威廉公式 (Hazen-Williams Formula)
下水道抽水機壓送管渠或壓力放流管，宜採用海森-威廉公式進行水力損失計算 [03.下水道工程設施標準.pdf | 第10條 p.8] [05.下水道系統設計及解說_第四章.pdf | 4.2節 p.17]：
$$V = 0.84935 \cdot C \cdot R^{0.63} \cdot S^{0.54}$$
$$h_f = 10.666 \cdot C^{-1.852} \cdot D^{-4.87} \cdot Q^{1.852} \cdot L$$
- $C$：流速係數（粗糙係數）：
  - 延性鑄鐵管 (DIP)、鋼管：$C = 100 \sim 130$ [05.下水道系統設計及解說_第四章.pdf | 4.2節 p.17]
  - 塑膠管 (HDPE / PVC)：$C = 130 \sim 150$ [05.下水道系統設計及解說_第四章.pdf | 4.2節 p.17]
- $h_f$：沿程摩擦水頭損失 ($\text{m}$)；$D$：管內徑 ($\text{m}$)；$L$：管長 ($\text{m}$)

## 2. 圓形管水力特性曲線 (Hydraulic Elements Curve)

圓形重力管在不同水深比（$h/D$，水深 $h$ 與管徑 $D$ 之比）下，其流速比 ($v/V$) 與流量比 ($q/Q$) 與滿管（$h/D=1.0$）時呈現特殊的非線性關係 [05.下水道系統設計及解說_第四章.pdf | 4.2節 p.19-21]：

```
水深比 (h/D)
1.0 ┼─────── 全滿流 (v/V = 1.00, q/Q = 1.00)
0.938 ┼────── 最大流量點 (q/Q = 1.076, v/V = 1.13)
0.813 ┼────── 最大流速點 (v/V = 1.140, q/Q = 0.988)
    │
0.5 ┼────── 半滿流 (v/V = 1.00, q/Q = 0.50, 水力半徑 R = D/4)
    │
0.0 ┴──────── 空管 (v/V = 0, q/Q = 0)
```

### 水力關鍵特徵點分析
1. **最大流速點 ($h/D = 0.813$)**：
   - 當管內水深達到管徑之 **$81.3\%$** 時，水力半徑 $R$ 增加之增益超越濕周磨擦阻力增加之負效應，斷面平均流速達到極限峰值，為滿管流速的 **$1.14$ 倍** [05.下水道系統設計及解說_第四章.pdf | 4.2節 p.20]。
2. **最大流量點 ($h/D = 0.938$)**：
   - 當管內水深達到管徑之 **$93.8\%$** 時，雖然流速略有下降，但過水斷面積 $A$ 與流速 $V$ 乘積達到最大值，輸送通水能力達到極限峰值，為滿管流量的 **$1.076$ 倍** [05.下水道系統設計及解說_第四章.pdf | 4.2節 p.20]。
3. **滿管反而通水能力下降之原因**：
   - 水深從 $0.938$ 增至 $1.0$ 時，管頂管壁全部浸潤接觸，增加了頂部潤周磨擦面積，而斷面積僅增加極微量，致使總通水阻力遽增，流量反降至 $1.00$ [05.下水道系統設計及解說_第四章.pdf | 4.2節 p.21]。
4. **半滿流特徵 ($h/D = 0.50$)**：
   - 水力半徑 $R = A / P = (\frac{1}{2} \cdot \frac{\pi D^2}{4}) / (\frac{1}{2} \cdot \pi D) = D/4$。
   - 與滿管的水力半徑完全相等 ($R_{\text{full}} = \frac{\pi D^2/4}{\pi D} = D/4$)。
   - 因此，**半滿流之流速等於全滿流之流速 ($v/V = 1.0$)，其通水量恰為全滿流之一半 ($q/Q = 0.5$)** [05.下水道系統設計及解說_第四章.pdf | 4.2節 p.21]。

## 3. 流速紅線限制與理想設計區間

```
重力污水管渠流速光譜 (m/s)
  0.0       0.6        1.0            1.8        3.0
───┴─────────┼──────────┼──────────────┼──────────┼───────► 流速
   【淤積沉澱】  ▲      【工程實務推薦理想區間】      ▲   【管壁磨損】
   (厭氧發酵) 最小紅線                           最大紅線 (高速衝蝕)
```

1. **法規強制紅線**：
   - **重力污水管渠最小流速**：**$\ge 0.6\text{ m/s}$**（計畫污水量時），嚴防管底泥砂有機物淤積與發酵產臭 [03.下水道工程設施標準.pdf | 第10條 p.8] [05.下水道系統設計及解說_第四章.pdf | 4.3節 p.25]。
   - **重力污水管渠最大流速**：**$\le 3.0\text{ m/s}$**（計畫污水量時），嚴防砂石刮磨破壞管壁與接頭沖蝕 [03.下水道工程設施標準.pdf | 第10條 p.8] [05.下水道系統設計及解說_第四章.pdf | 4.3節 p.25]。
   - **雨水及合流管渠流速**：最小流速 $\ge 0.8\text{ m/s}$，最大流速 $\le 3.0\text{ m/s}$ [03.下水道工程設施標準.pdf | 第10條 p.8]。
2. **工程推薦理想設計區間**：
   - 重力污水管渠理想流速應保持在 **$1.0 \sim 1.8\text{ m/s}$** [05.下水道系統設計及解說_第四章.pdf | 4.3節 p.26]。
   - 壓力輸水管渠經濟流速建議取 **$1.2 \sim 2.1\text{ m/s}$** [05.下水道系統設計及解說_第四章.pdf | 4.3節 p.27]。
